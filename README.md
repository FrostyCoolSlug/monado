# Monado Rift CV1 Fork

This is a fork of Monado that integrates the Rift CV1 tracking MRs 
(
    [2978](https://gitlab.freedesktop.org/monado/monado/-/merge_requests/2978),
    [2941](https://gitlab.freedesktop.org/monado/monado/-/merge_requests/2941),
    [3015](https://gitlab.freedesktop.org/monado/monado/-/merge_requests/3015)
),
along with a small fix when they're together, and an AI built commit that ports the existing controller code under
the same fusion code the HMD uses, allowing it to use multiple cameras and IMUs together.
